# Retail POS

Simple inventory-focused POS system.

Initial customer:
Perfume retail store.

Main goals:

- Create sales
- Reduce inventory
- Track stock
- Help identify products to reorder


## Technology

Frontend:

- Flutter POS
- Angular Admin


Backend:

- Firebase Authentication
- Firestore
- Cloud Functions


## MVP

The system contains:

1. Product management
2. Inventory management
3. Order creation
4. Stock tracking


## Important

Do not build unnecessary ERP features.

Keep the system simple.
