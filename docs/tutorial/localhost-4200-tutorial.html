Sign in & navigate

Start with an administrator account.

http://localhost:4200/login

  1. Open http://localhost:4200 in your browser. If you are signed out, the app takes you to Admin sign in.
  2. Enter your administrator Email and Password, then select Sign in.
  3. Use the left sidebar to open each management screen. Select Sign out in the header when finished.
An employee code is for the POS client. Admin sign-in requires an account with an active OWNER profile and a store assignment.

Use the dashboard for a daily overview

Πίνακας Ελέγχου shows today’s completed sales, order count, average receipt, seven-day sales, low stock and recent orders. Select Ανανέωση to refresh.

Prepare your store

Create the records that products and recipes will use.

1 · Brands and categories

Open Μάρκες (/brands). Enter Όνομα μάρκας, optionally add a code, leave Ενεργή selected and click Δημιουργία μάρκας. Repeat in Κατηγορίες (/categories) using Όνομα κατηγορίας and Δημιουργία κατηγορίας.

At least one active brand and category are needed before creating a product. Use the search field to locate existing records.

2 · Employees

Open Υπάλληλοι (/employees). Enter Όνομα υπαλλήλου and Κωδικός υπαλλήλου, select the active checkbox, then click Δημιουργία υπαλλήλου. The employee code is used to enter the POS.

The same screen has Έγκριση ακύρωσης παραγγελίας: enter and confirm a six-digit manager code, then select Ορισμός κωδικού. The POS requests this code before cancelling a sale.

3 · Packaging supplies

  1. Open Αναλώσιμα (/consumables), then + Νέο Αναλώσιμο.
  2. Enter the supply name, optional code, unit and optional cost price. Keep the active checkbox selected.
  3. Select Δημιουργία Αναλωσίμου. Repeat for bottles, caps or other materials used in your recipes.
Example setup: create a “Demo Brand”, a “Perfume” category, and a “30 ml bottle” supply. These are tutorial examples; enter them only in a suitable training store.

Checkpoint

Confirm that the new records appear in their lists and show an active status. Create supplies before building a variant that consumes them.

Build variant templates

A variant defines a sale format, recipe and suggested price.

http://localhost:4200/variants

  1. Choose + Νέα Παραλλαγή. Enter Όνομα Παραλλαγής, optional code, total size and unit.
  2. Choose Τύπος Συσκευασίας: Χύμα (BULK) for a recipe, or Συσκευασμένο (PACKAGED) for a ready-made item.
  3. Enter the selling price and, if relevant, cost price. For BULK, enter base and essence amounts in ml.
  4. For BULK, select the required Αναλώσιμα Συσκευασίας and specify how many of each are consumed.
  5. If offering a special bottle, enable Δυνατότητα Επιλογής Special Μπουκαλιού, select its supply record and set the extra charge.
  6. Keep Ενεργό selected and click Δημιουργία Παραλλαγής.

Create your first product

Attach compatible variants and decide how they appear at checkout.

http://localhost:4200/products/new

  1. Open Προϊόντα and select + Νέο Προϊόν.
  2. Enter Κωδικός Προϊόντος and Όνομα Προϊόντος; select a brand and category.
  3. Set Κατηγορία Συσκευασίας: BULK tracks liquid volume; PACKAGED tracks pieces. Set gender if needed.
  4. Optionally enter Συστατικά (για την ετικέτα). The field allows up to 500 characters and the interface requests uppercase, comma-separated ingredients.
  5. Under Παραλλαγές προϊόντος, select the available formats. Set each selected variant’s Τιμή Πώλησης (€) and optional Τιμή Κόστους (€).
  6. Expand Σειρά εμφάνισης στο POS. Drag the selected variants or use the arrow buttons to order them. The first variant is selected automatically at the POS.
  7. Keep Ενεργό Προϊόν selected and click Δημιουργία προϊόντος.

Find and maintain products

In the product list, search by code, name or brand, or filter by category. Open an existing product’s edit action to update its details and select Αποθήκευση αλλαγών.

Assign a variant to several products

Select product checkboxes in the list. Choose Παραλλαγή προς ανάθεση and click Προσθήκη στα επιλεγμένα. Review the result message and check the affected products.

Checkpoint: confirm the product’s code, active status and number of variants in the list. Creating a product is separate from receiving its stock.

Receive & correct inventory

Choose the stock mode carefully: the meaning of the number changes.

http://localhost:4200/stock-movements/new

  1. Open Κινήσεις Αποθέματος, then + Νέα κίνηση.
  2. Select the movement mode from the tabs below.
  3. Search by item code or name and choose a suggestion. Use + Επιλογή αναλωσίμων to select packaging supplies. You can include several items.
  4. Enter the quantity for every relevant row. Liquid fields use L; piece fields use τεμ.. Check Τρέχον and the calculated Νέο υπόλοιπο.
  5. Enter Αιτιολογία (reason). It is optional for purchases and required for adjustments or losses. Fix any row errors, then select Καταχώριση.
ModeWhat to enterExample
Παραλαβή
Receipt		Quantity received; adds stockCurrent 2 L + received 1 L = 3 L
Διόρθωση / Απογραφή
Count / adjustment		Actual counted balanceCurrent 2 L; enter 1.8 L → new 1.8 L
Απώλεια
Loss		Quantity lost; subtracts stockCurrent 2 L − lost 0.2 L = 1.8 L
1 litre = 1,000 ml. To receive 500 ml, enter 0.5 L. In count mode, enter the actual balance, rather than the difference.

Verify the result

Check the saved movement in the history. Use Συναλλαγές for grouped events and Αναλυτικές κινήσεις for individual changes. For an order event, select Προβολή to see stock effects.

Open Απόθεμα (/inventory). Search for the item and confirm the available quantity. Adjust the low-stock thresholds, item type or Μόνο χαμηλό απόθεμα filter to focus your review.

Review sales & expenses

Trace orders and keep employee spending visible.

Inspect an order

http://localhost:4200/sales-history

  1. Open Ιστορικό Πωλήσεων. Search by employee name or order ID.
  2. Check the date, employee, item count, total and status: ΟΛΟΚΛΗΡΩΜΕΝΗ means completed; ΑΚΥΡΩΜΕΝΗ means cancelled.
  3. Select Αναλυτικά beside an order. Review each product, variant, quantity, unit price and line total. A special-bottle indication appears when applicable.
  4. Select Απόκρυψη to collapse the details. Use stock movement history when you need to inspect the related inventory changes.

Record an expense

http://localhost:4200/expenses

  1. Open Έξοδα. Select an active Υπάλληλος.
  2. Enter Ποσό (€), choose Μετρητά (cash) or Κάρτα (card), and enter a description.
  3. Select Προσθήκη εξόδου.
  4. Filter by employee and Από / Έως dates, then select Ανανέωση. Confirm the new entry and the total, cash and card summaries.
  5. To change an existing expense, use its edit action, adjust the available fields and select Αποθήκευση. Select Άκυρο to leave the edit.
Training example: a €12 cash expense for packaging supplies should increase the expense total and cash expense total by €12 within the selected period.

Daily review

Compare recent orders with the sales history, review unexpected stock movements, record expenses against the appropriate employee, and then generate the report for the same date range.

Reports & quick fixes

Export a sales summary, then close out your session.

http://localhost:4200/sales-report

  1. Open Αναφορά Πωλήσεων. Set Από (from) and Έως (to) for the reporting period.
  2. Review the daily employee rows and Σύνολο ημέρας. Columns separate cash sales, card sales, cash expenses and card expenses.
  3. Select Εκτύπωση / PDF. In your browser’s print dialog, choose Save as PDF and save the report.
  4. For a spreadsheet, select Εξαγωγή CSV. When importing, choose a semicolon separator and the appropriate decimal-comma settings.
  5. Select Sign out when your review is complete.
Καθαρά μετρητά = cash sales − cash expenses. This is a cash subtotal, not a full profit calculation. Example: €100 cash sales − €12 cash expenses = €88 net cash.
